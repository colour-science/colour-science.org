**Colour** started in 2013 as a personal API shared with
`The Moving Picture Company <http://www.moving-picture.com>`__.

Generic objects have been extracted, reorganised and are now provided as a nice
packaged API while keeping the undisclosable code private.

The idea for the `Matplotlib <http://matplotlib.org>`__ implementation came from
Mark Kness's excellent `ColorPy <http://markkness.net/colorpy/ColorPy.html>`__
Python package.
