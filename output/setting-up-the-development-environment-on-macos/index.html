Setting Up the Development Environment on macOS

This guide covers the macOS setup for contributing to Colour. It uses Homebrew and includes optional steps for Visual Studio Code, Graphviz and CTL. It was originally contributed by @tjdcs.

Homebrew

If you need Homebrew, follow the official installation instructions.

uv

Install uv:

brew install uv

The project setup below uses Python 3.13, which uv can install automatically.

Cloning Colour's Repository

Fork the Colour repository, then replace YOUR-GITHUB-USERNAME with your GitHub username:

git clone https://github.com/YOUR-GITHUB-USERNAME/colour.git
cd colour
git switch develop

Working with Visual Studio Code from the Terminal

Create the development environment:

uv sync --python 3.13 --all-extras
uv run prek install

uv installs OpenImageIO into the project's virtual environment as part of the optional dependencies.

Opening Visual Studio Code

From the colour directory:

code .

If code is unavailable, open the Command Palette in Visual Studio Code and run Shell Command: Install 'code' command in PATH. Select the .venv/bin/python interpreter for the project.

Running the Unit Tests / Preflight

Run the tests and doctests with:

uv run invoke tests

To run the full preflight, including formatting, static checks, hooks, tests and examples:

uv run invoke preflight

Graphviz (Optional)

Install Graphviz if you need to render conversion graphs:

brew install graphviz

CTL (Optional)

Colour's Color Transformation Language wrapper needs the ctlrender command. Install the Homebrew CTL formula if you are working on that functionality:

brew install ctl

See Also

The contributing guide covers updating your fork, creating a branch and opening a pull request.
