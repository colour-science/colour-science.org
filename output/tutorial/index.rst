Start with the `installation guide </installation-guide/>`__ or run the
interactive tutorial in Google Colab.

    to run the examples in your browser.
-   `Open the How-To notebook <https://colab.research.google.com/notebook#fileId=1NRcdXSCshivkwoU2nieCvC3y14fx1X4X&offline=true&sandboxMode=true>`__
    for worked examples of specific colour science tasks.
